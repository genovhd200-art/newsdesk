# NewsDesk на GitHub (безплатно)

Новините се събират от GitHub Actions на всеки ~5 минути и се публикуват в GitHub Pages. Няма сървър, няма карта.

## Пускане (10 минути, всичко през сайта на GitHub)

1. На github.com: **New repository** → име `newsdesk` → **Public** (важно: за публично хранилище Actions е безплатен без лимит) → Create.
2. **Add file → Upload files** → качи ВСИЧКО от тази папка освен `.github` (index.html, collect.py, core.py, feeds.json, clubs.json, x.json, README.md и папката `site` с `privacy.html`) → Commit.
3. **Add file → Create new file** → в полето за име напиши точно `.github/workflows/update.yml` → постави съдържанието на файла `update.yml` → Commit.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. **Actions → „Обнови новините“ → Run workflow**. След ~2 минути сайтът е на `https://ТВОЕТО-ИМЕ.github.io/newsdesk/`.

Първото пускане превежда до 500 заглавия, следващите довършват останалите.

## Лимити (за да не се стига до плащане)
- Actions за публично хранилище: безплатно, без лимит на минути.
- Pages: ~100 GB трафик/месец (мек лимит). Страницата пита на 2 минути и получава „не е променено“ (304), когато няма нови данни.
- GitHub спира планираните пускания, ако в хранилището няма никаква активност 60 дни. Тогава натисни **Run workflow** (или направи малка промяна) и тръгват пак.
- Графикът „на 5 минути“ понякога се бави до 10–15 минути. Това е нормално за GitHub.

## Какво още не работи тук
Вход, синхронизация между устройства и предложения на сайтове се връщат във втората стъпка (малък Cloudflare Worker). Дотогава мониторингите и прочетеното се пазят в браузъра на устройството.
